# React SPA - Anime Quote App

A single-page React application that consumes a third-party REST API to retrieve and display random anime quotes.

This is an older project kept publicly as part of my development archive. The external API originally used by the application has since been deprecated, so some functionality may no longer work.

## Tech Stack

- React
- JavaScript
- Axios
- REST API
- CSS

## How It Works

The application acts as a lightweight API client:

1. The user requests a random quote.
2. The React client sends a request to the anime quote API.
3. The returned quote data is rendered in the UI.

## Running Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run at `http://localhost:3000`.
